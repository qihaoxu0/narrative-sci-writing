# 证据、参考风格与中英一致性

## 主张与材料对齐

对影响结论的主张建立最小记录；复杂整稿才需要独立表格：主张 → 证据位置 → 状态 → 可用表述 → 尚缺什么。

状态可为已观察、推导成立、解释、待验证或材料未提供。“未提供”不等于研究者没做过，“解释”不等于测量事实。

需要补实验时优先提出最能区分竞争解释的一项，并说明若结果不支持假设应怎样收窄主张。写作不自动触发训练、改阈值或删失败案例。

## 建设性修改示例

原句：该方法利用量子机制获得普适优势。

证据：只有单个公开数据集的离线比较，经典控制校准后差异很小。

合适改写：在该公开数据的离线评价中，我们比较了原始分数和采用相同校准流程的经典对照；校准后，先前观察到的概率损失差距明显缩小。

下一项：若仍研究机制差异，先指定能区分该机制与最强经典等价实现的对照。这是论点校正，不是写一连串“不声称”。不能换成“协同突破挑战”等词后保留原来的无依据结论。

## 提取参考论文写法

只在任务需要时进行，不把局部编辑变成大型文献审查。

1. 优先采用用户指定且全文可读的近邻论文；自行寻找时说明其与任务或期刊的关系并核实原文。仅有摘要只能做摘要层面判断。
2. 通常3—5篇可提取共同特征，篇数不是完成标准。按章节记录问题怎样收窄、转折位置、段落功能、证据出现时机和解释语气。
3. 风格规则标明来源位置，区分共同模式、单篇习惯与期刊硬性要求。不推测没有读到的章节。
4. 归纳成少量可执行规则，如“给出具体失效条件后再引入方法”，而非“像顶刊一样有深度”。用户要求保存或后续确需复用时再写风格文件。
5. 用新稿的真实论证填入这些功能，不抄句子、照搬不适用结构或把参考论文当作新稿结果的证据。

## 中文定稿与英文转写

语义锚点包括对象与条件、样本规模、指标和方向、基准、统计与因果强度、完成状态和重要限制。用户直接要求英文时无需另起中文审批。

“在开发集上降低了NLL，但未提高分类准确率”可以忠实转写为：

> The method reduced NLL on the development set without improving classification accuracy.

不能改成improved overall performance、demonstrated superior generalization或validated a new mechanism。中文本身有事实矛盾时指出并建议核实，不悄悄将错误译成流畅英语。

按主张检查中英差异，语序可重构，数值和证据强度不能升级。用户锁定的章节、术语和范围优先，不为润色添加新贡献、自辩或限制。

## 减少防御性表达，保留科学精度

写清“何种条件下观察到什么”，替代无关风险宣言；必要边界要与实际影响连接。

- 空泛：我们不声称适用于所有场景，也不保证所有机制均被验证。
- 具体：评价覆盖两个采集批次；跨设备迁移尚未检验，因此当前结果支持同设备条件下的比较。

不一律删除may、suggest或“可能”。主动语态通常更清楚，但不强制把学科自然表达都改成We。术语准确性优先于机械去词表，不承诺通过AI检测。
